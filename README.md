# Maksym | Frontend Developer Portfolio

A personal portfolio website built to showcase my projects, skills, and frontend development journey. The project focuses on high-quality UX, featuring a dark-mode glassmorphism UI, custom sound integrations, magnetic interactions, and a fully responsive design.

## Live Preview
**[View Live Project](https://maksym-portfolio-three.vercel.app)**

## Design Reference
Custom dark-mode design utilizing neon accents, translucent blurred containers, and a typographic pairing of 'Outfit' and 'Fira Code'. 

## Technologies Used
* **React** 
* **React Context**
* **TypeScript**
* **SCSS Modules**
* **Vite**
* **Lucide React** (Icons)

## Getting Started
To run this project locally, follow these steps:

1. Clone the repository:
```bash
git clone https://github.com/KitiAWP/maksym_portfolio.git
cd maksym_portfolio
```

2. Install dependencies:
```bash
npm install
```

3. Run the project locally:
```bash
npm start
```

## Features
* Custom Audio Context: Global sound toggle with distinct audio feedback for navigation, toggles, and magnetic hover zones.

* Smart Touch Detection: Magnetic buttons and hover sound effects are automatically disabled on touch devices to prevent double-firing and UX bugs.

* Fully Responsive: Custom SCSS mixins guarantee a seamless layout transition from desktop to mobile screens.

* Glassmorphism UI: Translucent cards with backdrop-filter, gradient borders, and clean typography.
